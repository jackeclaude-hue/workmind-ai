## 🛠️ Stack Tecnológico

Este proyecto está construido bajo una arquitectura web nativa y ligera, garantizando tiempos de carga ultrarrápidos y total independencia de frameworks pesados:
* **Estructura:** HTML5 semántico.
* **Estilos:** CSS3 avanzado con diseño adaptable (*Responsive Design*), variables personalizadas y temas profesionales.
* **Lógica e Interfaz Dinámica:** JavaScript nativo (*Vanilla JS*) aplicando manipulación eficiente del DOM y gestión de estados de la SPA.
* **Control de Versiones:** Git & GitHub.
* **Infraestructura y Despliegue:** Vercel (CD Global optimizado).

---

## 📋 Características Principales

1. **Cuestionario Dinámico de Diagnóstico:** 6 preguntas estratégicas enfocadas en procesos, herramientas y adopción tecnológica.
2. **Motor de Cálculo y Semaforización:** Puntuación ponderada en tiempo real (0-100%) con conmutación visual automatizada según los umbrales de desempeño:
   * 🔴 **Rojo (<40%):** Fase Inicial / Urgente.
   * 🟠 **Naranja (40% - 74%):** En Proceso / Oportunidad de mejora.
   * 🟢 **Verde (>=75%):** Optimizado / Alto rendimiento.
3. **Plan de Acción Guiado:** Recomendaciones tácticas inmediatas basadas en los resultados obtenidos.
4. **Privacidad Garantizada (Zero-PII / Zero-Auth):** Arquitectura frontend estática que no recopila ni almacena información personal identificable (PII) en servidores externos.
